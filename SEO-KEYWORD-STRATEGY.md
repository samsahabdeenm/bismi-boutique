## Technical SEO checklist
- Keep one preferred HTTPS host and make all alternate hosts redirect to it. Confirm the domain resolves to the actual website before expecting crawling.
- In Google Search Console, inspect the homepage and key pages with URL Inspection; confirm Google-selected canonical, crawl result and indexing status.
- Submit https://bismiboutique.online/sitemap.xml after confirming the site is live and returns HTTP 200. Re-submit after important changes.
- Confirm robots.txt is reachable and does not block CSS, JavaScript, images or pages intended for indexing.
- Check for broken internal links, redirect chains, duplicate titles, missing descriptions and incorrect canonicals.
- Add meaningful, unique alt text to real product images. Compress images and use modern formats where supported.
- Keep mobile usability and Core Web Vitals healthy; test with PageSpeed Insights.
- Use structured data only for facts visible on the site. Validate with Schema Markup Validator and Google's Rich Results Test. Local business structured data does not guarantee a rich result.
- Keep sitemap URLs canonical, indexable and returning HTTP 200. Do not include preview URLs or redirected URLs.
- Add actual category/product pages with useful unique text when the catalogue is verified; do not create thin keyword-only pages.

## AEO / AI search / LLM readiness
- Keep the brand name, contact details, address and official social URLs identical across the website and public profiles.
- Keep llms.txt accurate as a helpful summary, but do not treat it as a guarantee of AI crawler access or citations.
- Use clear headings, direct answers, descriptive category names and accessible HTML text.
- Make product facts explicit and current: name, price, availability, size, colour, fabric, shipping and return rules only when verified.
- Connect official Instagram and YouTube profiles to the website and link back to the website from those profiles where possible.
- Publish useful original content such as fabric/care guides, size guidance and styling tips based on actual products and expertise.
- Avoid keyword stuffing, fabricated reviews, fake schema, doorway pages and mass-produced low-value AI content.
